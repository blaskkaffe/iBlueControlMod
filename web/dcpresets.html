One click sets what the Dreamcast sees (the controller type) and the button mapping of one output. The mapping is BlueRetro's default one: L1 = Z, R1 = C, L2 / R2 = the left / right trigger, left stick = stick, right stick = right stick (types that have one), L3 / R3 do nothing and can be mapped on the Advance page.


Disconnect all controllers from BlueRetro before connecting for configuration.

Only for this game
